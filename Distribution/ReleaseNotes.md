# What’s New in TimeVault 1.0.1

- Snapshot selections are now clearly marked, so you can see at a glance which backups are set as the older and newer comparison points.
- Snapshot selection is more reliable across the browser, pickers, and custom folder choices.
- Improved visibility of the Use older and Use newer controls on selected snapshot rows.
- Clearer recovery options when TimeVault needs Full Disk Access to read a backup.
- Comparison warnings are easier to review and dismiss.
