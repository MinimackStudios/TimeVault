Installing TimeVault

1. Drag TimeVault.app onto the Applications shortcut.
2. Double-click Open TimeVault.command.
3. Terminal may ask for confirmation before running the file.

The command only removes the quarantine attribute from the installed
copy of TimeVault and then opens it. It does not disable Gatekeeper.

Alternatively, Control-click TimeVault in Applications, choose Open,
and confirm that you want to open it.
